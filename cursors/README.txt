GUNDAM-00Q 指针方案
====================
素材全部来自 00Q 全刃式模型的**实拍提取**：GN 剑 5 / GN Bit / GN 光束军刀 / GN 太阳炉。
没有原作以外的造型（不做 GN 笔、不做 GN Sword II Blaster）。

安装（推荐）
  右键 out\install.ps1 -> 使用 PowerShell 运行（会请求管理员权限，装完立即应用）
  之后可在 设置 -> 蓝牙和其他设备 -> 鼠标 -> 其他鼠标设置 -> 指针 里选 "GUNDAM-00Q"

安装（备选）
  右键 out\GUNDAM-00Q.inf -> 安装

卸载
  右键 out\uninstall.ps1 -> 使用 PowerShell 运行

静态 .cur 内嵌 256/128/96/64/48/32 六档，Windows 自己择优；
动态 .ani 内嵌 128/96/64/48/32 五档（**全部用 PNG 存**）。

  ★ 档位用 PNG 存几乎不花钱：BMP 无压缩（96px 一档 38 KB），PNG 省 67~86%。
    实测 Windows **确实会使用 PNG 档**（指定 128 取回渲染，与按 128 渲染的源图逐像素一致）。
  ⚠️ icon 块有**两条**上限，都要看：
       字节      ≤ 69,632 B
       解码像素  ≤ 96,000（≈96×1024）—— **这条 PNG 压不掉**，档位越多越大就越占

关于动态
  十一个槽是动态的：
    01 正常选择 = GN 剑 5，整体呼吸发光 + GN 粒子外飘
    03 后台运行 = GN 太阳炉，暗态发光闪烁 + 粒子（低干扰）
    04 忙       = GN 太阳炉，Trans-Am 三红发光闪烁 + 粒子
    06 文本选择 = GN 光束军刀，呼吸发光 + 侧向粒子
    07 手写     = 机甲手持 GN 光剑（钢笔角度），呼吸发光 + 粒子
    09~12 调整大小 = 两只 GN Bit **分离 / 结合**
    13 移动     = 四片 GN Bit 刃，**旋翼旋转**
    15 链接选择 = 指向手，**按下时食指缩回**
  炉子不转 —— 原作里 GN 太阳炉就是静止的，转起来是"机械装置"的语汇。
  其余 4 槽静态（02 / 05 / 08 / 14）。

关于尺寸
  Windows 默认按 32px 显示。**在 4K/2K 屏上把"鼠标指针大小"滑杆调大即可**：
    设置 → 辅助功能 → 鼠标指针和触控 → 大小
  每一档都是独立生成的（各自的描边、光效、粒子都在**该档的像素**上画），
  不是同一张拉伸 —— 在 512 母版上画的粒子缩到 32px 会**直接消失**。
  静态可到 256px、动态可到 128px，都不糊。
